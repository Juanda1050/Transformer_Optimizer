Transformer Optimizer - Windows Release

Este ejecutable fue preparado para Windows y genera resultados para cada instancia.

Uso:
1. Abre la carpeta release/windows.
2. Ejecuta transformer_optimizer.exe.
3. El programa genera el archivo results.csv en la misma carpeta o en la ruta del proyecto.

Requisitos del sistema:
- Windows 10 o superior
- .NET runtime no es necesario para este programa

Archivo generado:
- results.csv
